# [오름] 복습 퀴즈 배틀

고전문법 복습시험(세종어제훈민정음·용비어천가·소학언해)을 카훗 스타일 실시간 퀴즈 게임으로 만든 것.

## 수업에서 진행하는 법

1. 프로젝터로 **host.html**을 연다 (배포 주소/host.html).
2. 퀴즈 카드(훈민정음/용비어천가/소학언해) 중 하나 클릭 → 화면에 **6자리 PIN**이 뜬다.
3. 학생들에게 접속 주소를 알려주고, 폰으로 접속해 **PIN + 실명 + 학교 + 닉네임**을 입력하게 한다.
4. 대기실에 닉네임과 인원수가 올라오는 걸 확인하고 **[게임 시작]**.
5. 문제 중에는 선생님 화면에도 학생과 같은 문제+선지가 표시된다. 하단에 "응답 n/m" 표시.
   - 제한시간이 끝나면 결과 화면으로 넘어간다. 전원 응답해도 자동으로 넘어가지 않는다.
   - 일찍 끊고 싶으면 **[결과 보기 (조기 종료)]** 버튼을 누른다.
6. 결과 화면: 정답(노란 막대) + 선지 분포 + 정답률 + TOP5. **[다음 문제 ▶]**로 진행.
7. 마지막 문제 후 **[🏆 순위 발표]** → [다음 순위 공개]를 눌러 5위→1위 공개.
   - **닉네임을 클릭하면 실명 공개.**
8. **[게임 종료 + 결과 저장]** → 구글 시트에 학생별 점수·문항별 정오답이 저장된다.

- 게임 도중 호스트 화면을 새로고침해도 "이어서 진행"으로 복구 가능.
- 학생이 새로고침해도 같은 폰이면 점수 유지된 채 재입장된다.

## 입장 방법 (PIN + QR)

- 대기실 화면에 **PIN과 QR이 함께** 표시된다.
- QR을 찍으면 PIN이 미리 입력된 입장 페이지가 열려서 이름·닉네임만 쓰면 된다.

## 문항·선지 셔플

- **게임(방)을 만들 때마다 문항 순서와 선지 순서가 새로 섞인다.**
- 같은 게임 안에서는 모든 학생 + 프로젝터가 같은 순서를 본다 (선지 분포 통계 일치).
- 구글 시트 기록은 항상 **원본 문항 번호(id) 순서**로 저장되고, 오답의 선지 번호도 원본 기준이라 회차가 달라도 비교할 수 있다.

## 점수 규칙

- 정답: **1000점 × 남은 시간 비율** (빨리 맞힐수록 높음)
- 오답/미응답: 0점
- 제한시간: 기본 20초, 합답형 25초 (data/*.js의 timeLimit)

## 파일 구조

- `index.html` + `js/player.js` — 학생 화면
- `host.html` + `js/host.js` — 선생님(프로젝터) 화면
- `data/hunmin.js` `yongbi.js` `sohak.js` — 문항 데이터 (수정하면 바로 반영)
- `img/` — 중세국어 단어 이미지
- `review.html` — 문항 검수 페이지 (정답·원본 대조)
- `AppsScript.gs` — 결과 기록용 (구글 시트에 부착)
- `js/config.js` — Firebase 설정 + 시트 웹훅 URL
- `tests/` — `node tests/game-core.test.js`, `node tests/data-check.js`

## 문항 수정법

`data/*.js`에서 해당 문항의 `choices`(선지)나 `answer`(0부터 세는 정답 번호)를 고치고 저장 → 배포(커밋/푸시)하면 끝.
검수는 `review.html`에서 한눈에 볼 수 있다.

## 인프라

- 실시간 동기화: Firebase Realtime Database (rooms/{PIN} 아래에 게임 상태)
- 결과 기록: Google Apps Script 웹훅 → 구글 시트
- 호스팅: GitHub Pages (정적 파일)
